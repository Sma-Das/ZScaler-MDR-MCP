# Contributing

Keep provider adapters small, explicit, read-only, and independently testable. Add verified endpoint references and synthetic tests for every provider. Preserve provenance, partial failures, timestamps, and hard ceilings.

Run `make ci` before opening a pull request. Never include customer incidents, tenant identifiers, credentials, hidden model reasoning, or raw automation objects in tests, screenshots, issue bodies, or commits. Document user-visible behavior and security limits.
